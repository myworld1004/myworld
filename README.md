## 규칙

- 새 앱은 맨 위에 파일을 두지 말고 **앱 이름으로 폴더**를 만들어 그 안에 둡니다.
- 각 폴더에는 그 앱의 `README.md`를 둡니다: 무엇을 하는 앱인지, 어디서 실행하는지, 파일 구성.
- 커밋과 PR 제목 앞에 앱 이름을 붙입니다. 예: `[엑스포] 백업 기능 추가`, `[5부제] 알림 시간 수정`
- 이 표에 새 앱을 한 줄 추가합니다.
