# 🚗 5부제 알리미

차량번호 끝자리를 설정하면 5부제(운행 제한) 날짜를 알려주는 웹앱(PWA)입니다.

- **오늘/내일 상태**: 앱을 열면 오늘이 5부제인지 크게 표시하고, 내일과 다음 5부제 날짜도 알려줍니다.
- **달력**: 이번 달 5부제 날짜를 빨간색으로 표시합니다.
- **캘린더 알림(추천)**: 앞으로 12개월치 5부제 날짜를 `.ics` 파일로 만들어 휴대폰 캘린더에 추가합니다.
  전날 저녁과 당일 아침에 휴대폰 캘린더가 알려주므로 앱을 열지 않아도 됩니다.
- **앱 알림**: 앱을 열었을 때 오늘·내일이 5부제면 알림을 띄웁니다.
- **설정**: 차량번호 끝자리(기본 3 → 날짜 끝자리 3·8인 날), 주말 제외 여부.

## 규칙

날짜(일)의 끝자리가 차량번호 끝자리와 같은 조이면 5부제입니다: 1·6, 2·7, 3·8, 4·9, 5·0.
끝자리 3번 차량은 매월 3, 8, 13, 18, 23, 28일입니다.

## 사용하기

정적 파일만으로 동작합니다. GitHub Pages 등에 올린 뒤 휴대폰으로 열고
"홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

로컬 확인: 이 폴더에서 `python3 -m http.server` 후 http://localhost:8000 접속.
